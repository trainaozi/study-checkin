# 学习打卡 · Study Check-in

一个**纯静态、离线可用**的学习打卡网站，全部 HTML / CSS / JS 及 Chart.js 依赖都内联在单个 HTML 文件中，断网也能用。

> 直接部署在 GitHub Pages 上，可免费在线访问。

## 功能特性

- **五个视图（单文件多视图路由）**：首页 · 打卡 · 每日计划 · 数据看板 · 历史记录
- **响应式布局**：PC 端左侧固定侧边栏导航，移动端底部 Tab 栏（自动适配）
- **小清新视觉**：统一主色 / 副色调、粒子背景动画、页面与卡片 CSS 入场动画
- **每日计划**：左右分栏，新建 / 编辑计划（科目、任务描述、开始 / 结束时间、循环方式：单次 / 每天 / 指定星期、备注）；开始时间用主色、结束时间用副色；可填写「今日学习具体项目」并按日期归档
- **打卡计时**：展示当日任务，开始 / 暂停 / 结束计时；结束弹窗采集掌握程度（1–5）与备注，记录时长、掌握度、备注
- **数据看板**：科目时长分布（环形图）、学习时长趋势（折线 / 双轴）、掌握程度统计（柱状图）、各科目平均掌握度、KPI 卡片与科目投入排行
- **历史记录**：打卡明细 + 每日归档，支持筛选与 CSV 导出（带 BOM，Excel 中文不乱码）；含 JSON 备份 / 恢复、清空数据
- **云同步 · 跨设备备份**：历史记录页可连接 GitHub Gist，把打卡数据加密备份到云端，换设备 / 清缓存后仍可恢复。采用 Web Crypto（AES-GCM + PBKDF2）加密你的 GitHub 令牌后再保存到本机，令牌不会明文落地；支持自动同步、手动同步、冲突合并与同步状态提示。**同一 GitHub 账号下自动复用同一份备份**（电脑和手机用同一个令牌即可自动同步，无需手动抄 Gist ID；若历史遗留多个备份会自动合并并清理）。**删除操作也会同步**（基于墓碑机制：本地删除计划 / 记录后，云端对应数据同步删除，其他设备也不会再"复活"已删除的数据）
- **数据持久化**：全部使用浏览器 `localStorage`，结构含版本号与容错处理（损坏数据自动降级、非法字段归一化）

## 使用方法

- **本地使用**：直接用浏览器打开 `index.html`（或 `学习打卡.html`）即可，无需任何服务器。
- **在线访问**：部署到 GitHub Pages 后，通过 `https://<用户名>.github.io/study-checkin/` 打开。

## 数据存储说明（重要）

所有打卡数据仅保存在**你当前浏览器**的 `localStorage` 中（key：`chenlu.study.checkin`）。

- ✅ 完全离线、隐私可控、不依赖服务器
- ⚠️ 换设备或清理浏览器缓存会丢失数据，建议定期在「历史记录 → 数据管理」中导出 JSON 备份
- 🌐 如需跨设备备份，可开启「历史记录 → 云同步 · 跨设备备份」，按提示输入 GitHub 个人访问令牌（仅需 `gist` 权限）和同步口令即可。**电脑和手机用同一个令牌连接后会自动指向同一份云端备份**，无需手动填写 Gist ID。
- ⚠️ 在线版是**纯前端**应用，每个访客的数据各自独立存储在本机，互不共享

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- [Chart.js 4.4.1](https://www.chartjs.org/)（UMD 完整版，已内联）
- 响应式布局 + CSS 动画 + Canvas 粒子背景

## 部署（GitHub Pages）

仓库根目录的 `index.html` 即站点入口。本仓库已配置 `.github/workflows/deploy.yml`，每次 `push` 到 `main` 分支会自动部署到 GitHub Pages。首次部署需在仓库 **Settings → Pages** 中将 Source 设为 `GitHub Actions`。
